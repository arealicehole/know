# V1 — Print / trade / custom manufacturing / sign shops  
*(Frank H1: quote + CRM hero)*

## 1. Pain and budget owner

| Pain | Who feels it | Who signs the check |
|------|--------------|---------------------|
| Quote lag / underbidding / lost RFQs | CSR + estimator + owner | **Owner / GM** (almost always) |
| Job tracking chaos (whiteboard, Excel, email) | Production manager | Owner |
| Art approval ping-pong | Art dept + sales | Owner (if overtime/rework burns margin) |
| “Software we already pay for doesn’t talk” | Office manager | Owner |
| IT downtime / ransomware fear | Everyone | Owner (often after a scare) |

**Budget owner:** owner-operator or family principal at shops under ~$5–10M revenue. IT/manager rarely has independent software budget without owner OK.  
**Confidence:** high (industry pattern); AZ-specific owner-centric SMB structure consistent with MSP/print vendor sales motions.

## 2. What they pay today for substitutes (cited)

### Shop management / quote-CRM software (SaaS)

| Product | Public price signal | Notes | Conf. |
|---------|---------------------|-------|-------|
| **Printavo** | **Lite $109/mo** (2 users, 20 quotes/invoices); **Standard $244/mo** (5 users, unlimited); **Premium contact** (20 users + $19/extra user) | Cloud shop management: quotes, pipeline, scheduling, catalogs (SanMar etc.), mockups | **High** — printavo.com/pricing |
| **shopVOX** | **from $99/mo + $19/user**; PRO **$199/mo + $39/user** | Strong pricing engine for signs/wraps/screen; SoftwareConnect 2026 roundup | **Med-High** — secondary roundup citing plans |
| **ShopWorks / ePS Pace / PrintVis / Ordant** | mostly **quote-only** in public roundups | Larger commercial / MIS class | **Low** public $ |

**Implication for Frank A:** a shop already spending **~$110–250+/mo** on Printavo-class tools has proven willingness to pay for *quote ops software*. Frank’s A-MO intro **$400 → $550** is **above** pure SaaS but can be justified only if the agent layer + keep-alive clearly beats “software seat” (labor hours saved on quoting, follow-up, CRM hygiene)—not as a cheaper Printavo.

### IT / tech substitutes

| Substitute | Public AZ / market signal | Conf. |
|------------|---------------------------|-------|
| Break-fix IT | Mobile Tech Support Phoenix **$100/hr + $20 travel** | High |
| MSP per user | Phoenix published bands ~**$100–$275/user/mo** (guides); FCG **$65 / $150 seat**; MBPS from **~$95** stacked; AZ MSP UNLIMITED managed **from $250/user** | High–Med |
| MSP project T&M | MBPS **$150/hr** std / **$300** after-hours; ITS blog **$150–$250/hr** break-fix band | High–Med |
| Fractional IT retainer | LocalEdge-style **$1.5–3k/mo** for 10–20 hrs; **from $2k/mo** package | Med (non-AZ primary) |

Print shops often run **lean IT**: QuickBooks + shop software + M365 + a “guy.” Full MSP per-user is common only once headcount and compliance pressure rise.

### Marketing / print production (not software)

Local incumbents (PRI Graphics, AlphaGraphics, Artisan Colour, Phoenix Signs & Apparel) own **production dollars**. They do **not** publish list prices. Buyers think in **job quotes**, not monthly retainers.  
**P-PERK** competes on **relationship + cost-plus**, not on replacing their presses—Frank brokers/near-costs while they remain production alternatives clients already know.

## 3. Typical contract shapes

| Spend type | Shape | Term |
|------------|-------|------|
| Shop MIS / Printavo-class | Monthly SaaS, cancel-friendly marketing | Month-to-month or annual |
| MSP | 12–36 mo common; onboarding fee; seat minimums | Multi-year risk |
| Break-fix | Hourly, min hours, travel fee | No term |
| AI automation agency | Setup fee **or** $0 setup + $179–500/mo bot; or one-time build $2.5–7.5k + tiny AI pass-through | Mixed |
| Commercial print vendor | PO / job quote; sometimes charge accounts | Transactional |

**Frank fit:** A as **setup + monthly** mirrors AI-agency and SaaS hybrid; B as **hours bank** mirrors fractional IT; AB should look like “one throat to choke” vs three vendors.

## 4. Sales motion that works locally (reasoned + AZ signals)

| Motion | Why it fits AZ print/sign | Evidence grade |
|--------|---------------------------|----------------|
| **Warm intro via print community / trade suppliers** | Shops trust peers and distributor reps more than cold SaaS | Reasoned high |
| **Vendor-adjacent** (ink, substrate, equipment techs) | Techs see broken quote workflows daily | Reasoned med |
| **Chamber / local business groups** | Phoenix metro SMB networking still relationship-led | Reasoned med |
| **Show up on a lost-quote pain story** | “How long from RFQ to sent quote?” demo | Reasoned high |
| **Do not lead with “AI”** | Competes with $20 ChatGPT objection; lead with **hours and missed jobs** | Reasoned high |
| **Cold MSP-style RMM pitch** | Wrong category; sounds like Coeus/FCG | Avoid |

AZ-specific: large metro + many family shops + heat/seasonality less relevant than for HVAC; **Spanish/English office mix** common in Valley service economy—bilingual ops is a plus if Frank has it (A³ markets bilingual; Automators markets bilingual).

## 5. Objections and counters

| Objection | Reality check | Counter |
|-----------|---------------|---------|
| “ChatGPT is $20” | True for chat; false for integrated quote/CRM/workflow with keep-alive | Show one real quote cycle: intake → price matrix → follow-up → deposit |
| “We have Printavo / shopVOX” | They may already; Frank is not a $109 clone | Position **on top / beside**: agents for chase, exceptions, cost span—not another status board |
| “We have a nephew / kid who does computers” | Common; Mobile Tech $100/hr is the professionalized version | B retainer = documented systems list + response SLA vs nephew availability |
| “Our printer handles menus” (if hybrid shop) | Production ≠ ops system | Separate **P** perk from **A** system; printer remains partner |
| “MSP already covers us” | MSP owns endpoints, not vertical quoting IP | Coexistence: Frank A is LoB app; MSP stays security/patch |
| “Too expensive vs $244 Printavo” | Fair sticker shock | Bundle AB value; intro A-MO $400 as pilot fence; quantify estimator hours |

## 6. Where Frank’s bundle wins

| Vs | Frank wins when… | Frank loses when… |
|----|------------------|-------------------|
| **Pure AI agency** | Buyer needs shop-floor quote truth + ongoing tech human, not only chatbot | Buyer only wants missed-call bot at $179–500 |
| **Pure MSP** | Buyer wants vertical agent product, not seats | Buyer needs HIPAA/CMMC NOC and 24/7 ticket factory |
| **Pure printer** | Buyer wants ops leverage + optional near-cost print perk | Buyer only needs a banner by Friday |
| **SaaS only (Printavo)** | Buyer still drowning in manual exceptions / multi-channel leads | Shop is happy inside one SaaS with trained staff |

**Win narrative (H1):** “Quote speed + follow-up agents + a real tech on retainer + print cost discipline”—one relationship.

# V2 — Restaurants / hospitality offer-board businesses  
*(Frank H2: menu / offer-board ops)*  
*Adjacent: barbers/salons — same offer-board pattern, smaller ticket*

## 1. Pain and budget owner

| Pain | Who feels it | Who signs |
|------|--------------|-----------|
| Price/86 updates slow across boards, print menus, delivery apps | GM / FOH manager | **Owner / multi-unit operator** |
| Missed calls / reservations / catering leads | Host / owner | Owner |
| Menu design dependency on printer or freelancer | Marketing-minded owner | Owner |
| POS + boards + Instagram out of sync | GM | Owner |
| “We already pay Toast” fatigue | Everyone | Owner (fee sensitivity high) |

**Budget owner:** independent and small-group owners; GMs influence but rarely sole sign-off. Multi-unit groups may have ops directors.  
**Confidence:** high pattern.

## 2. What they pay today for substitutes (cited)

### POS (platform gravity)

| Source | Signal | Conf. |
|--------|--------|-------|
| Toast official pricing page | Plans marketed **from $0/mo** (starter kit eligibility) + standard POS plans; custom enterprise | Med (marketing floor) |
| Toast blog (2026 POS cost article) | Standard Point of Sale plan cited around **$69/mo** in third-party summaries of Toast materials; hardware extra | Med — confirm on toasttab.com/pricing at lock time |
| Deelo secondary (May 2026) | All-in **~$250–500/mo** small café; **~$700–1,200/mo** 30-seat FSR common all-in claims | **Low-Med** (secondary) |

**Implication:** restaurants already tolerate **hundreds $/mo** platform spend. Frank A-MO must not feel like “another $550 SaaS” without POS-adjacent ROI story (labor, 86 accuracy, upsell boards).

### Digital menu board software

| Platform | Entry public price | POS sync notes | Conf. |
|----------|-------------------|----------------|-------|
| Kitcast | **from $7/screen/mo** | API on Pro | High (vendor) |
| DotSignage | marketing **from ~$10/mo** class | TV / Fire stick | Med-High |
| FoodShot comparison (Aug 2026, vendor pages scraped) | cluster **$5–$30/screen**; Menuboard Manager **$89 / $199 / $299** tiers; full POS sync often **top tier only** | High as secondary synthesis |
| Menuboard Manager | Toast, Olo, Qu, Aloha, Micros integrations marketed | High features; price via comparison | Med-High |

**Year-one math (FoodShot):** 3-screen QSR software-only band roughly **$288–$11k** depending on tier—photography/content often dominates cost.

### Print menus / static boards (local AZ)

| Vendor | Role | Public $ |
|--------|------|----------|
| PRI Graphics menus/tags | Ongoing menu reprints | unknown |
| AlphaGraphics Camelback menu boards | Fabricated boards | unknown |
| Phoenix Signs & Apparel | Menus, tents, storefront, wraps | unknown |
| Artisan Colour | Menus + in-store signage (testimonial on phoenixcommercialprinting.com) | unknown |

Buyers often prefer **reprint cycles** over software until price volatility or multi-daypart pain forces digital.

### IT / automation substitutes

Same MSP/break-fix bands as V1. AI receptionist competitors (**$179–500/mo**, sometimes $0 setup) are **more directly competitive** in restaurants than in print shops because missed-call → empty table is visceral.

### Marketing agencies

Public AZ restaurant-agency retainers not reliably published in this pass → **unknown**. National small-business marketing retainers often land mid-four-figures/mo for full service; many indies use owner + Canva + a freelancer. Treat as **gap**.

## 3. Typical contract shapes

| Layer | Shape |
|-------|-------|
| Toast / POS | Hardware + software + processing; sticky switching costs |
| Menu board SaaS | Per screen / mo; annual discount |
| Print menus | Job-based; rush fees |
| AI receptionist | Month-to-month $179–500 common in marketed offers |
| Frank-like systems | Setup + monthly keep-alive competes with both SaaS and agency |

## 4. Sales motion that works locally

| Motion | Fit |
|--------|-----|
| **Via POS reseller / integrator relationships** | Toast ecosystem is gravity well |
| **Via print/sign vendors** (PRI, AlphaGraphics) | They already talk menus; co-sell ops layer carefully |
| **Owner peer groups / neighborhood restaurant associations** | Trust |
| **Demo on live 86 / happy hour daypart** | Beats abstract AI pitch |
| **Avoid lunch rush cold walk-ins** | Operational respect |
| **Spanish-capable support** | Valley advantage if true |

## 5. Objections and counters

| Objection | Counter |
|-----------|---------|
| “ChatGPT is $20” | Boards + POS truth + dayparts ≠ chatbot |
| “Toast does menus” | Toast is POS; board networks and offer ops still fragment; Frank integrates the *change workflow* |
| “Our printer handles menus” | True for paper; slow for daily specials; P-PERK can still supply print while A runs digital/ops |
| “We tried digital boards; ugly / always wrong” | Content + POS sync tier matters (FoodShot: photo quality > CMS brand); sell ops discipline |
| “$550/mo after Toast fees” | Intro fence $400; start single workflow (catering leads or board updates); AB only if IT pain real |
| “Nephew set up the Fire Stick” | Works until multi-location or staff turnover—keep-alive is the product |

## 6. Where Frank’s bundle wins

| Vs | Wins | Loses |
|----|------|-------|
| **Pure AI agency** | Needs human tech + print path + multi-system ops | Only wants $179 phone bot |
| **Pure MSP** | Hospitality offer-board product, not tickets | Needs full PCI/HIPAA-ish stack and 24/7 NOC |
| **Pure printer** | Dynamic ops + optional near-cost print | One-time menu reprint job |
| **Menu SaaS only** | Agent + retainer + exceptions across channels | Single-screen Canva loop is “good enough” |

**Win narrative (H2):** “Offer board stays true—prices, 86s, dayparts—without the owner living in three apps; tech guy on call; print when you still need paper.”

### Adjacent: barbers / salons

Same offer-board and booking pains at **smaller ACV**. Use as **upsell adjacency**, not primary ICP. Price sensitivity higher; $179 AI receptionist competitors bite harder. Prefer package **lite A** or project HR over full AB until proven.
